# Store POS - نظام الإدارة والمبيعات الشامل

نظام متقدم لنقاط البيع وإدارة الموارد التجارية، صُمم هندسياً كحل جذري للأسواق التي تعاني من التذبذب الحاد في أسعار صرف العملات وعدم استقرار البنية التحتية للطاقة. يوفر النظام بيئة عمل آمنة ومستقرة تضمن حماية رأس المال من تآكل القيمة نتيجة تقلبات السوق.

## القيمة السوقية
يقدم النظام حلولاً برمجية مباشرة لمشاكل واقعية ومعقدة تواجه التجار يومياً، مما يضمن استمرارية العمل بدقة مالية عالية وتجاوز العقبات التشغيلية في البيئات الاقتصادية غير المستقرة.

## الميزات التنافسية الأساسية

* **معالجة تذبذب العملات (Dynamic Multi-Currency Handling):**
  الربط اللحظي والمباشر بين عملتين (الدولار والعملة المحلية) في جميع شاشات النظام، بدءاً من المشتريات وصولاً إلى التسعير والمبيعات. يقوم النظام بحساب التكلفة، تسعير المنتجات، واستخراج هوامش الربح لكل قطعة ولكل فاتورة بدقة متناهية تتكيف تلقائياً مع تغيرات سعر الصرف اليومية، مما يمنع حدوث أي خسائر ناتجة عن فروقات العملة.

* **محرك المسودات المحلي (Local Draft Engine):**
  آلية حفظ سريع تعتمد على تخزين هيكل الفواتير والعمليات قيد الإجراء محلياً في ملفات نصية معزولة عن قاعدة البيانات الرئيسية. تضمن هذه الميزة عدم فقدان أي بيانات حساسة أو جهد مبذول عند الانقطاع المفاجئ للتيار الكهربائي، وتوفر استرجاعاً تلقائياً للمسودات فور إعادة تشغيل النظام.

* **الإدارة المالية وحسابات الشركاء (Financial & Partners Module):**
  وحدة مالية متكاملة مخصصة للمشاريع ذات الملكية المشتركة. تتيح إدارة الأرصدة الافتتاحية، تسجيل الإيداعات والسحوبات الشخصية لكل شريك، وتوزيع نسب الأرباح بدقة بناءً على صافي الربح الفعلي بعد خصم كافة المصاريف التشغيلية والتوالف.

* **نظام الحماية وصلاحيات المدير (Admin Security Mode):**
  طبقة أمنية تمنع التعديل على الحساسيات المالية، نسب أرباح الشركاء، أو حذف الفواتير المكتملة دون المصادقة الإدارية. يتكفل النظام آلياً بعكس القيود وتحديث المخزون بدقة تامة عند تنفيذ أي عمليات حذف لضمان تطابق الأرصدة المستودعية.

## التقنيات المستخدمة
* **لغة البرمجة:** C# (WinForms)
* **قاعدة البيانات:** Microsoft SQL Server
* **تقنية الوصول للبيانات:** ADO.NET
* **المعمارية:** Multi-tier Architecture

## الجمهور المستهدف
* المؤسسات والمحلات التجارية التي تتطلب تسعيراً لحظياً يتوافق مع تقلبات الصرف.
* المشاريع التجارية القائمة على شراكات متعددة وتتطلب تتبعاً مالياً دقيقاً.
* مراكز التجزئة والجملة، والصيدليات التي تحتاج إلى استقرار تشغيلي عالي.

## تجربة النظام
هذا المستودع مخصص لعرض المنتج ولا يحتوي على الكود المصدري حفاظاً على حقوق الملكية الفكرية. 

لتجربة النظام بشكل عملي والاطلاع على واجهات الاستخدام، تتوفر النسخة التنفيذية (Executable) في قسم Releases، وهي جاهزة للتحميل والتثبيت المباشر على أنظمة التشغيل.
